# Tickets

Conventions live in `TICKETS.md` in the **forty-workspace** repo. They are the
same for every project; this file records only what is specific to this one.

- Prefix: `TIL` (see `ticket_prefix` in the workspace `projects.yml`)
- Open tickets in `tickets/todo/`, finished ones in `tickets/done/`
- Next id: one higher than the highest already in either folder
- The pull request that does the work also moves the file into `done/`

Spec lives at `SPEC.md`; hosted design at `HOSTED.md`.
